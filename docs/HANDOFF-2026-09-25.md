## Traps this lane has paid for and will pay for again

1. **A tool's default path.** `derive-link-provenance` without `--cache` reads `<repo>/scraper/cache` (763 files),
   not `/var/lib/netzspec-api/cache` (12,231). It cost `held` 9,706 → 650 before the refusal guard existed.
   Always pass `--cache` on the box.
2. **The publish scripts refuse a dirty tree** — by design. Commit first; `publish-layers.sh` then builds from the
   commit and verifies the live bytes against what it checked.
3. **`ls data/ledger` drives `publish-arrangement.sh`.** A ledger file left behind for a merged-away category
   publishes a category that does not exist. `build-cup-ledger.mts` now refuses a category with no live hardware.
4. **A verification run needs a frozen tree.** Do not edit while `npm test` runs; its failures AND its passes stop
   meaning anything.
