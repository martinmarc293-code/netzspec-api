# 2026-09-29 — splitter 1.8.2, and `ieee_standards` gets an inheritance class

Reviewer rulings on batch 4 (Cisco lane). Both were forced by measurement, recorded here with it.

## 1. NORM 1.8.2: the pre-bullet head, and runs of spaced middle dots

**Measured (29 Sep, Cisco, current facts, the real `renormalize.decide()` at 1.8.1):** of the replays the stale-version
pass would write, a member GREW by more than 25 characters (a split undone) in **92 of 511** `ieee_standards` changes and
**116 of 873** `supported_protocols` changes; `rfc_compliance` 0 of 286. No change dropped any letter or digit of an old
member (the 6 ieee hits are `802.11a/n/ac` expansions, which a character check cannot follow).

Two shapes inside the growth were defects:
- **the head before the first bullet** was taken as one bullet item, so a comma list and a heading ahead of the bullets
  became ONE member and swallowed a `;` — `WAP571E-A-K9`: `IEEE 802.11ac, 802.11a, …, 802.11i (WPA2 secur ; Safety:`.
- **a run of spaced middle dots** (`·`, U+00B7) was not a bullet — `M9500FMS1K9=` stored one 150-character member.

**Ruling:** split the head with the ordinary separators (a bullet ITEM keeps its commas — a bullet says where it ends, the
head has no bullet); a spaced `·` occurring two or more times is a bullet (one is a title separator, an unspaced one a
product of units). One sabotage each: both go red when the rule is reverted, each on exactly its own case.

**Re-measured at 1.8.2:** grew **35** ieee (all norm_v 1.0.0) and **95** protocols. Every one classified, 0 unexplained:
the grown member is either one bullet item kept verbatim (1 + 8 distinct raws — the item-keeps-its-commas design) or a
member whose commas sit only inside brackets (1 + 7 — `(RFCs 1577, 1755, and 1626)` is one citation). Text lost: 0.
MISS-level suite diff against the session baseline: new 0, gone 0, moved 0.

## 2. `ieee_standards` → inheritance class C

The 44 truncated inherited `ieee_standards` cells (legacy writes by apply-specs run 61, 4 Sep) could not be replayed through
`apply-extract`, because `canInherit` refuses a field in no class and `ieee_standards` was in none — while it is 100%
inherited on switches. **Ruling:** the class was missing, not the fact; classify, then replay. Not a retraction (it would
withdraw 44 true values for a splitter defect) and not a flag (a recorded gap wearing a value).

**C, not A**, on the precedent of `supported_protocols` (C): a standards list is stated once per series, but a PoE and a
non-PoE member of one sheet can carry different 802.3 lists, and a per-model list must win.

Added by hand with a dated section: the legacy generator (`src/pipeline/legacy/apply-inheritance-classes.mjs`) rebuilds
the whole file from a 2 Sep journal into `lib/`, which would drop every dated section since.

**The freeze pins neither the inheritance classes nor `NORM_VERSION`** — `arrangementFreeze` stays 32/0 after both
changes. Whether it should pin the classes is a question put to the reviewer, not decided here.
