## Environment traps that cost time today

- Python is **`python3.11`**, not `python` — `Get-Process python` matches NOTHING and reports
  live jobs as dead. Use `Get-CimInstance Win32_Process` + CommandLine; CPU-seconds is the only
  honest liveness signal.
- Harness background Bash tasks get **reaped**; launch long jobs with PowerShell `Start-Process`.
- `cmd | head; echo $?` reports **head's** exit code — it nearly hid five real `tsc` errors.
- Long local CPU work and long Atlas I/O in the same window starve the DB connection.
